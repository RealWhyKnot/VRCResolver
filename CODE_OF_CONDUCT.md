# Code of conduct

This project uses the **Contributor Covenant, version 2.1**.

The full text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Short version

Be respectful. Assume good faith. Criticise ideas, not people. Harassment, personal attacks, sexualised content and discriminatory language aren't welcome in issues, PRs, Discussions, or anywhere else tied to this project.

## Scope

It applies to all project spaces (this repository, its Discussions, its issue tracker, and any chat or social channel that represents the project), and to public spaces when someone is representing the project.

## Reporting

If you experience or see behaviour that breaks this code, contact the maintainer privately through a [GitHub Security Advisory](https://github.com/RealWhyKnot/VRCResolver/security/advisories/new), which works for conduct reports too, or by direct message to **@RealWhyKnot** on GitHub.

Reports are handled confidentially. Consequences range from a warning to a permanent ban from project spaces, at the maintainer's discretion, following the enforcement guidelines in the Contributor Covenant.
